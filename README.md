# 排球裁判輔助系統

國立宜蘭大學資訊工程學系 軟體工程課程 期末專案（第 11 組）

## 背景與問題

1. 在排球場報隊打球時需要算分，但單靠記憶或手算通常不方便，所以希望有手機或網頁來幫助記分。
2. 有時需要擔任裁判，但站位、暫停次數、換人、比分紀錄等，可能只能用手寫來看，所以也想加入這些功能。

## 需求

### A 模式：野場算分系統

1. 分數顯示
2. 翻分（下滑得分、上滑扣分）
3. 到 25 分時結束；雙方 24 平手時，需領先 2 分才結束

### B 模式：裁判輔助系統

1. 號碼選擇（預設 1～30 號）
2. 隊伍名稱輸入
3. 站位號碼選擇
4. 發球權輪轉
5. 換人功能（一個選手只能換兩次，並且只能與同一人互換）
6. 暫停功能（一局最多兩次，每次 30 秒）
7. 分數功能（直接按分數加分，計分規則同 A 模式）
8. 分數得分歷史

## 專案目標

### 希望改善什麼

1. 減輕場邊算分的負擔，並用手機直接把分數展示出來，減少爭議。
2. 減輕裁判看站位、算暫停次數的負擔，讓裁判能專心判決場上情況。

### 如何判斷達成目標

1. **計分功能正確性**：系統能正確計分，並依排球規則判斷比賽結束條件。
2. **裁判輔助功能正確性**：確認球員換人、站位輪轉、發球提示、暫停計時功能正常運作。
3. **提升裁判效率**：透過實際比賽模擬，比較使用本系統與不使用系統時各自的錯誤記錄次數。

## 已釐清事項

| 問題 | 決定 |
|---|---|
| A、B 模式是否能在比賽中切換 | 不可 |
| 比賽規則 | 依正式室內六人制規則 |
| B 模式站位輪轉如何判斷 | 取得發球權時自動輪轉 |
| 計分錯誤 | 提供修正功能 |

## 待確認事項

- 決勝局分數：正式室內規則的第五局打到 15 分，目前需求寫的是一律 25 分。
- 換人上限：正式規則每局每隊最多 6 次換人，目前需求寫的是每位選手兩次。
